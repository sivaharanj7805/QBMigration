Security Practices

Enterprise-grade security for your financial data

🛡️ Security First: ForensicBridge was designed from the ground up with security as a core principle; not an afterthought.

🔐 Encryption

🔒 Data at Rest

All data is encrypted using AES-256-GCM with unique per-file keys. Encryption keys are protected using AWS KMS or DPAPI.

AES-256-GCM

🌐 Data in Transit

All network communications use TLS 1.3 with forward secrecy. We enforce HTTPS on all endpoints.

TLS 1.3

🔑 Password Storage

Passwords are hashed using Argon2id with memory-hard proof-of-work, the winner of the Password Hashing Competition.

Argon2id

📜 Forensic Integrity

Every record is hashed with SHA-256 to create an immutable audit trail for forensic verification.

SHA-256

🏗️ Architecture

🗑️ Zero-Persistence

Financial data is processed in isolated containers and automatically deleted within 24 hours of migration completion.

🇨🇦 Canadian Data Residency

All data is processed and stored exclusively in Canadian data centers (AWS ca-central-1, Montreal).

🔄 Isolated Environments

Each migration runs in its own isolated AWS environment, preventing cross-contamination between clients.

🧹 Secure Deletion

Files are overwritten with cryptographic patterns (DoD 5220.22-M standard) before deletion.

🔒 Access Control

🚫 Account Lockout

Accounts are automatically locked after 5 failed login attempts to prevent brute-force attacks.

⏱️ Rate Limiting

API endpoints are rate-limited to prevent abuse and denial-of-service attacks.

🎫 OAuth 2.0

QuickBooks integration uses Intuit's official OAuth 2.0 flow. We never see or store your QBO credentials.

📝 Audit Logging

All authentication events, data access, and administrative actions are logged for security monitoring.
