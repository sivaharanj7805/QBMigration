ForensicBridge Inc. ("ForensicBridge," "we," "our," or "us") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our QuickBooks Desktop to QuickBooks Online migration software and related services (the "Service").
By using the Service, you consent to the data practices described in this Privacy Policy. If you do not agree with this Privacy Policy, please do not use the Service.
1. Information We Collect
1.1 Account Information
When you create an account, we collect:
•	Full name
•	Email address
•	Company/firm name (if applicable)
•	Password (stored in hashed form using Argon2id)
•	Billing information (processed by Stripe; we do not store full credit card numbers)
1.2 QuickBooks Data
When you use the Service to migrate data, we temporarily access:
•	QuickBooks Desktop company file data (.QBW)
•	Chart of accounts, customers, vendors, employees, items
•	Invoices, bills, payments, journal entries, and other transactions
•	QuickBooks Online OAuth tokens (for authorized API access)
1.3 Automatically Collected Information
•	IP address
•	Browser type and version
•	Operating system
•	Date and time of access
•	Pages visited and features used
•	Migration job metadata (file size, transaction counts, processing time, success/failure status)
2. How We Use Your Information
We use collected information to:
•	Provide the migration service (extract, transform, and load your QuickBooks data)
•	Generate cryptographic verification hashes and audit certificates
•	Export data to Caseware Working Papers format (if selected)
•	Process payments and manage subscriptions
•	Send transactional emails (migration status, receipts, account notifications)
•	Provide customer support
•	Improve and optimize the Service
•	Detect and prevent fraud or unauthorized access
•	Comply with legal obligations
3. Data Processing & Security
3.1 How We Handle Your Financial Data
Aspect	Our Practice
Encryption in Transit	TLS 1.3 for all network communications
Encryption at Rest	AES-256-GCM encryption for all stored data
Financial Data Storage	Processed in memory only; NOT permanently stored on our servers
Temporary Files	Encrypted; automatically deleted upon migration completion
Data Location	Canadian data centers only (AWS ca-central-1, Montreal)
PII Protection	Automatic redaction of SSN, credit card numbers before processing

3.2 What We DO Store
•	Account information (name, email, company name, hashed password)
•	Migration job metadata (company name, file name, file size, entity counts, timestamps)
•	Verification results (trial balance comparisons, hash verification status)
•	Audit trail logs (who accessed what, when)
•	Encrypted OAuth tokens for QuickBooks Online access
•	Cryptographic hash signatures (for verification purposes only; not reversible to original data)
3.3 What We DO NOT Store
•	Raw financial transaction data (invoices, bills, payments, line items)
•	Customer or vendor personal details from your QuickBooks data
•	Bank account numbers or full credit card numbers
•	Employee Social Security Numbers (automatically redacted during processing)
